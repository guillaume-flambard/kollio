# UI

The shared design language. Publishes Living Canvas tokens and theme consumed by the web app; holds no product logic and no domain state.

## Language

**LivingCanvas**:
The Kollio design language: an airy workspace where ideas, evidence, and collaborators stay visibly connected.
_Avoid_: Theme alone, skin, template

**SemanticToken**:
A named design value (color, spacing, radius, type) carrying meaning, not a raw value. Screens use tokens, never literals.
_Avoid_: Variable alone, hex value, magic number
