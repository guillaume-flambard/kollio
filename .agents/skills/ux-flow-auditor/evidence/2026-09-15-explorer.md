## Findings

1. **Dead/duplicated control: `ideas.explorer.recent`.** The "Recent" rail
   button (`index.vue:138-140`) is hard-wired with `:aria-pressed="false"` and
   its click handler is byte-for-byte the same `replaceFilters({ stage:
   undefined, role: undefined, realism_min: undefined })` as the "For you"
   button (`index.vue:133-137`, key `ideas.explorer.forYou`). It can never
   report a pressed state and does not reorder by recency, so the control is
   misleading and effectively unreachable as a distinct destination. No
   scenario pins its behaviour.
2. **Touch target below the 44px convention.** Pagination links
   (`.ideas-results-pagination a`, `index.vue:250`) set `min-height: 40px`,
   while the mobile rail buttons use `min-height: 44px` (`index.vue:267`). On
   phones the pagination targets are 4px under the convention used elsewhere in
   the same screen. Pagination is not exercised by the responsive spec.

## Verdict

EXPLORER-01 and EXPLORER-04 AUDITED for fr and en.
