- [ ] 1.1 Re-run the archived seeded-pilot acceptance on the current revision and record which interface, integration, and provider boundaries remain simulated or opt-in in `acceptance.md`.
- [ ] 1.2 Identify two pilot participants and create pseudonymized role labels; verify the acceptance record contains no decision text, source material, credentials, prompts, or personal identifiers.

## 2. Run the first real decision loop

- [ ] 2.1 Have the owner frame a real Decision Space and invite the second participant; verify evidence references establish two distinct authenticated roles.
- [ ] 2.2 Capture evidence references for each participant's contribution, the recorded decision, the experiment, the observed outcome, and the confirmed learning; verify every required milestone is marked passed or incomplete without inference.
- [ ] 2.3 Record material friction at the milestone where it occurred; verify each item distinguishes an observed blocker or confusion from a feature request.

## 3. Measure voluntary return and close the debrief

- [ ] 3.1 Observe whether a participant creates or joins a second Decision Space without an immediate facilitator prompt; verify the record identifies the outcome as voluntary return, guided action, or no return.
- [ ] 3.2 Conduct a short pilot debrief and give every material friction a disposition; verify each disposition is a follow-up OpenSpec change, an explicit deferral, or a documented non-reproduction.
- [ ] 3.3 Complete `acceptance.md` with scenario-to-evidence mapping, privacy boundary, simulated-test boundary, and an explicit conclusion limited to the evidence gathered.

## 4. Validate and archive the planning record

- [ ] 4.1 Run `openspec validate validate-real-decision-loop --strict` and verify the change artifacts remain structurally valid.
- [ ] 4.2 Archive the change only after every scenario has evidence or is explicitly recorded as unmet; verify no unmet milestone is represented as completed adoption.
